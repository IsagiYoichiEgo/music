# Проверка обновлённого оформления

Дата: 6 ноября 2026.

- Сохранён src/api.ts без изменений: endpoints, credentials: include, JSON и обработка серверных ошибок.
- npm test: 8 из 8 существующих контрактных тестов прошли.
- npm run build: TypeScript и Vite прошли.
- Просмотрены главная, диалог регистрации и профиль: desktop 1440×900, mobile 390×844; дополнительно узкий экран 320×740.
- На 320 px document.scrollWidth = document.clientWidth = 305 px при innerWidth 320 px с вертикальной полосой прокрутки; горизонтального переполнения нет.
- Регистрация: пустые поля, несовпадающие пароли, показ/скрытие пароля, блокировка полей при загрузке, успешный переход ко входу.
- Вход: успешное открытие профиля. Профиль: изменение имени/специализации/гонорара, отрицательный гонорар, серверная ошибка сохранения и повтор, сообщение об успехе, восстановление после reload.
- Выход: серверная ошибка и успешный повтор. Диалог: фокус на логине, клик внутри не закрывает окно, фон и Escape закрывают.
- Проверены видимые состояния фокуса; CSS отключает анимацию и плавную прокрутку при prefers-reduced-motion.
- Консоль браузера: ошибок JavaScript не обнаружено.

Все изменяющие запросы браузерных сценариев направлялись во временный локальный Vite middleware с подменой API URL только на время QA. Настоящие аккаунты не создавались, общий учебный сервер не изменялся. Временный конфиг удалён; обычная сборка и preview используют исходный API. Проверка реальных cookie в стороннем домене не повторялась.

Не добавлены вымышленные записи, концерты, участники или отзывы. Сохранена существующая иллюстрация, её демонстрационная природа подписана. Изменения подготовлены локально, без push и deploy.
