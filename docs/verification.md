# Проверки Thunder bend

Дата: 1 ноября 2026, Asia/Almaty.

- npm run build: TypeScript + Vite, exit 0.
- npm test: 8 тестов, 8 passed. До реализации все 8 воспроизводимо падали.
- HTTP-контракт: endpoints, JSON, credentials: include, server field errors, malformed profile, network errors.
- Браузер desktop 1440px и mobile 390px: главная, регистрация, неверный пароль, повтор пароля, показ пароля, загрузка с блокировкой кнопок, профиль, ошибка сохранения и повтор, отрицательный гонорар, восстановление сессии, ошибка выхода и повтор.
- На 390px горизонтальной прокрутки нет; исключений JavaScript нет.
- Реальный API из браузера: регистрация 201, login, GET профиля, PATCH имени/специализации/bio/гонорара, reload с сохранением сессии, logout и reload без сессии.
- Учебная учётная запись создана только для теста. Пароль и cookie не записывались в файлы и не выводились; после проверки выполнен logout.
- В исходниках нет сохранения паролей или токенов в localStorage/sessionStorage.
- Скриншоты главной и реального профиля просмотрены.
