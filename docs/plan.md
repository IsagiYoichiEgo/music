# Thunder bend — ДЗ8

React + TypeScript, Vite без Babel. Статический сайт группы и аккаунт музыканта. Backend: https://inai-col2.fishrungames.com/api/. Регистрация, вход, выход, GET/PATCH профиля; специализации получаем с сервера. Реальный login возвращает UserProfile и HttpOnly sessionid с SameSite=None; используем credentials: include, без сохранения паролей и токенов в localStorage.
