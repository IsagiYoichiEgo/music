# Thunder bend — обновление оформления

Цель: сделать существующий учебный сайт убедительным примером для портфолио: выразительная музыкальная главная и аккуратный рабочий личный кабинет.

Содержание и границы: сохраняем название, существующую концертную иллюстрацию и реальную регистрацию, вход, выход, просмотр/редактирование профиля. Не добавляем вымышленные треки, участников, концерты, отзывы или достижения. Учебный характер отмечен прямо. API, cookie и валидация сохраняются. Проверка форм — только с локально подменёнными ответами, без создания аккаунтов и изменения общего сервера.

Рассмотрены: компактная косметическая правка (слишком слабый результат для портфолио); афишная главная с множеством вымышленных разделов (нет исходных данных); концертная обложка и понятный профиль (выбрано в рамках делегированных пользователем решений).

Палитра: сцена #111310, панель #1c201b, текст #f4f1e8, приглушённый #b1b7aa, свет сцены #e8bb73, граница #3a4136. Тёплый свет взят из имеющейся иллюстрации, без стандартного кислотного акцента.

Шрифт: Impact / Arial Narrow для крупного латинского названия, системный Segoe UI для русского текста, навигации и форм. Заголовок — главный выразительный элемент; остальные блоки спокойные, выравнивание слева.

Композиция: тёмная верхняя панель, крупная концертная обложка с названием слева и музыкантами справа, нижняя строка с честной подписью иллюстрации. Далее один компактный раздел о профиле с перечнем настоящих возможностей и CTA. Формы — светлый фокус, подписи над полями, достаточно места для ошибок, кликабельные области от 44 px. Профиль — боковая идентификация и основная форма.

Проверка направления: убраны декоративные счётчики, придуманные жанры и рекламные лозунги. Основной акцент — существующая сцена и крупное название. Движение ограничено одним входом обложки, состояниями кнопок и диалогом, с prefers-reduced-motion.
